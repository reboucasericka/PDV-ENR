# Release 1.0.0

**Data:** 2026-08-07

## Escopo

Primeira versão estável do POS System para portfólio: fluxo completo de balcão, do login aos relatórios.

## O que entrou nesta versão

- Autenticação por sessão
- Seleção de loja e ciclo de caixa (abrir → vender → fechar → histórico)
- Catálogo (produtos e categorias)
- Vendas com múltiplos métodos de pagamento e troco em dinheiro
- Recibo + comanda de cozinha via impressão HTML
- Dashboard com indicadores e gráficos
- Relatórios filtráveis
- Configurações da empresa
- Documentação de portfólio (`docs/`)
